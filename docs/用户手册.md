# 小白上手指南：从零跑起一个多 Agent 协作系统

> 这篇指南假设你**没有任何编程基础**，连命令行都没打开过。跟着一步步点，就能在自己电脑上跑起来。
> 全程只需要：一台 Windows 电脑 + 一个邮箱注册的 DeepSeek 账号 + 大约 20 分钟准备时间。

---

## 这个软件能干什么？

一句话：**你只用提需求，它替你指挥三个 AI 干活**——一个负责派活（调度），一个负责写代码（编码），一个负责挑毛病（评审）。写得不满意会打回去重写，写完了还会检查"说好的文件是不是真的交出来了"。

整个过程会在你的浏览器里实时画出流程图，你可以看着它一步一步干活。

---

## 第一步：申请一个 AI 密钥（约 5 分钟）

这个软件需要调用 DeepSeek 的大模型，所以先要一个"钥匙"（API Key）：

1. 打开 <https://platform.deepseek.com> ，用手机号或邮箱注册
2. 登录后点左侧**「API keys」**→ **「创建 API key」**
3. 给它起个名字（随便写，比如 `my-key`），点创建
4. **立刻复制弹出来的那串 `sk-` 开头的字符**——它只显示这一次，关掉就再也看不到了
5. 先别关网页：点左侧**「充值」**，充几块钱就够了（这个软件用的是便宜的轻量模型，几块钱能玩很多次）

把这串 `sk-...` 记在记事本里，后面要用。

---

## 第二步：准备运行环境（两条路线二选一）

两种方式任选一种，跑出来的效果一样。

### 路线 A：安装 Docker（没接触过 Docker 的话，选路线 B 更简单）

Docker 是用来"一键搭环境"的工具，装它就像装微信一样简单：

1. 打开 <https://www.docker.com/products/docker-desktop/> ，点 **Download for Windows** 下载安装包
2. 双击下载好的安装程序，一路点 **OK / 下一步**（保持默认勾选不要动）
3. 装完后**重启电脑**（它要求重启一次）
4. 重启后双击桌面的 **Docker Desktop** 图标启动它
5. 第一次启动要等 1-2 分钟初始化，看到窗口左下角状态变成 **running**（绿色），就好了

> 小提示：以后每次开机想用本软件，都要先打开 Docker Desktop 等它变绿，就像开机要先开 WiFi 一样。

### 路线 B：安装 Python（更轻量，不用装 Docker）

1. 打开 <https://www.python.org/downloads/> ，点页面上最大的黄色 **Download Python** 按钮下载安装包
2. 双击安装程序，**第一屏务必勾选最下面的「Add python.exe to PATH」**，再点 **Install Now**（不勾选后面会找不到命令）
3. 装完验证：按 `Win + R` 输入 `cmd` 回车，在黑窗口输入 `python --version` 回车
   - 显示出版本号（比如 `Python 3.13.x`）→ 成功，记住用 `python`
   - 提示"不是内部或外部命令"→ 改输入 `py --version`，能显示版本号也行——记住改用 `py`（第五步照此替换）

## 第三步：把软件下载到自己电脑上（约 3 分钟）

**方式一（推荐，不用装任何工具）：**

1. 打开仓库主页 <https://github.com/LiMuBai-QiuWuJi/agent-workflow>
2. 点绿色的 **Code** 按钮 → 点 **Download ZIP**
3. 下载完成后，右键这个 ZIP 文件 → **全部解压缩** → 选一个你找得到的位置（比如 D 盘根目录，**中文路径也可以**）
4. 你会得到一个 `agent-workflow` 文件夹，记住它在哪

**方式二（如果你装了 git）：**

```bash
git clone https://github.com/LiMuBai-QiuWuJi/agent-workflow.git
```

---

## 第四步：打开命令行（别怕，就三行命令）

命令行就是"打字指挥电脑的地方"。打开它最省力的方法：

1. 双击打开第三步解压出来的 `agent-workflow` 文件夹
2. 在文件夹**最上面的地址栏**（显示路径的那一条）里，用鼠标把原来的文字**全选删掉**
3. 输入 `cmd` ，按回车

会弹出一个黑窗口，而且你会发现光标已经在 `agent-workflow` 目录里了——后面所有命令直接粘进去就行。

> 其他打开方式（知道就行）：按 `Win + R` 键，输入 `cmd` 回车；或点开始菜单，输入 `cmd` 回车。

---

## 第五步：跑起来！

先照第四步的方法，在 `agent-workflow` 文件夹里打开黑窗口（地址栏输 `cmd` 回车）。然后按你第二步选的路线，把命令逐行粘进去（在黑窗口里点一下右键就是粘贴），每粘一行按一次回车。

### 路线 A（Docker）

**第 1 行**（构建环境，第一次要下载东西，耐心等 10~30 分钟，看到进度走完、出现新的输入提示符才算完）：

```bash
docker build -t agent-workflow .
```

**第 2 行**（启动！把 `sk-你的key` 换成第一步复制的那串钥匙）：

```bash
docker run -p 8000:8000 -e DEEPSEEK_API_KEY=sk-你的key agent-workflow
```

### 路线 B（Python）

**先做一件事（只需一次）**：在 `agent-workflow` 文件夹里新建一个文本文档，文件名改成 `.env`（注意前面有个点），里面只写一行，把钥匙换成你自己的：

```ini
DEEPSEEK_API_KEY=sk-你的key
```

**第 1 行**（准备专属环境，一分钟内完成）：

```bash
python -m venv .venv
```

> 提示找不到 `python`？改用 `py -m venv .venv`（第二步第 3 条让你记的就是这个）。

**第 2 行**（进入这个环境，成功后行首会多出 `(.venv)` 字样）：

```bash
.venv\Scripts\activate
```

**第 3 行**（装依赖，第一次约 1-2 分钟）：

```bash
pip install fastapi uvicorn openai pydantic python-dotenv python-docx pypdf
```

**第 4 行**（启动！钥匙程序会自动从刚才的 `.env` 文件里读）：

```bash
uvicorn web_server:app --port 8000
```

> 如果提示 `uvicorn` 不是命令：先跑一遍 `python -m pip install uvicorn`，再把第 4 行换成 `python -m uvicorn web_server:app --port 8000`（`python` 不行就换 `py`）。

### 最后一步（两条路线一样）

打开你的浏览器（Chrome/Edge 都行），地址栏输入：

```
http://localhost:8000
```

看到深色界面、中间有个输入框，**就成了！**

1. 点界面**右上角的 ☰ 菜单按钮**
2. 找到**录播回放**入口，随便选一条（一条是"一次通过"，一条是"打回重写后再通过"）
3. 看着流程图自己动起来、走完整个评审链

看完你就明白这软件是怎么回事了，而且**一分钱不花**。

## 第七步：真刀真枪跑一次

回到输入框，粘贴这句现成的话（这是一个最容易成功的小任务）：

```
写一个斐波那契数列脚本，输出前 20 项，保存到文件
```

点开始后：

1. **看上面那张总览图**——绿色方块会一个接一个亮起来，像地图一样显示干到哪了
2. **看下面那张轨迹图**——记下整个过程：派活 → 编码干活 → 评审挑毛病 → 交付核验
3. 等弹窗跳出来（一般 1-3 分钟）——**成功**的弹窗会告诉你产出了什么文件、放在哪、怎么用

### 产出文件在哪？

- **路线 B（Python）**：文件直接就躺在 `agent-workflow` 文件夹里的 `demo_out\` 子文件夹中，打开就能看
- **路线 A（Docker）**：文件在容器里面，要拷回来：另开一个 cmd（照第四步的方法，同样在 `agent-workflow` 文件夹里开），运行：

```bash
docker cp agent-workflow:/app/demo_out/. ./demo_out/
```

然后回到 `agent-workflow` 文件夹，`demo_out` 里就是你的文件（比如 `demo_out\web\` 下的脚本）。

> 想更省事？启动时加一句 `-v %cd%\demo_out:/app/demo_out`，文件就直接落在你的文件夹里，不用拷（详见进阶篇）。

## 常见问题（卡住先来这里）

**Q：浏览器打不开 localhost:8000？**
多半是没跑第五步第 2 行，或者那行报错了。回到黑窗口看看有没有红色的字。

**Q：黑窗口报错 "port is already allocated"（端口被占用）？**
你电脑上的 8000 端口被别的程序占了。把第 2 行命令里的两个 8000 都换成 8001，浏览器地址也换成 `http://localhost:8001`。

**Q：第 1 行命令卡在下载，半天不动？**
国内访问 Docker 官方源很慢。打开 Docker Desktop → 右上角齿轮（设置）→ 左侧 **Docker Engine**，在大括号里加一行镜像加速地址，点 **Apply & Restart**，然后重新执行第 1 行：

```json
"registry-mirrors": ["https://docker.m.daocloud.io"]
```

**Q：报错说 API key 不对 / 401 / unauthorized？**
钥匙复制错了（多复制了空格或少复制了字符），或者 DeepSeek 账号没充值。路线 A 重新复制钥匙再跑启动命令；路线 B 检查 `.env` 文件（必须在 `agent-workflow` 文件夹里、文件名就是 `.env`、内容只有一行钥匙），改完重新跑第 4 行命令。

**Q：Windows 弹出"是否允许此应用访问网络"？**
点**允许**。不点它就没法在浏览器里访问。

**Q：文件夹放在中文路径下可以吗？**
可以，已实测（比如 `D:\我的文件\agent-workflow` 没问题）。不过路径里**不要有空格**更稳妥。

**Q：怎么停下来？**
回到跑着的那个黑窗口，按 `Ctrl + C` 两下；或者干脆关掉黑窗口，再打开 Docker Desktop 点停止按钮。

## 进阶篇（想折腾再看）

- **用 .env 文件存钥匙**（不用每次敲长命令）：在 `agent-workflow` 文件夹里新建文本文件，改名 `.env`，内容一行：`DEEPSEEK_API_KEY=sk-你的key`，启动命令改成：
  ```bash
  docker run -p 8000:8000 -v %cd%\.env:/app/.env agent-workflow
  ```
- **不装 Docker 直接跑（需要 Python 3.10 以上）**：见 [README](README.md) 的"本地运行"一节
- **换模型 / 调参数**：改 `run_config.txt`（默认用 DeepSeek 便宜的 deepseek-flash，想换更强的模型改 `coder.model` 那一行）
- **看更多机制细节**：见 [README](README.md) 的"核心机制"一节
