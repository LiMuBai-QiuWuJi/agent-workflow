# AI 智能体团队 · 自我介绍页

## 交付物
- `self-intro.html` —— 单文件自我介绍网页（核心交付物，评审以它为准）

## 打开方式
双击 `self-intro.html` 即可，或拖入任意现代浏览器（Chrome / Edge / Firefox / Safari）。
无需服务器、无需联网、无任何外部依赖（不引 CDN、不引字体、不引图片，图标全部使用系统 emoji 与 CSS 绘制）。

## 页面板块（对应任务六项要求）
| 板块 | 锚点 | 内容 |
| --- | --- | --- |
| ① 我是谁 | `#who` | 定位为「项目经理型调度 Agent」，负责把需求拆解给编码岗与评审岗 |
| ② 团队编制 | `#team` | coder（实现代码并声明交付文件）、tester（审查并给出【评审结论:通过/不通过】） |
| ③ 运行逻辑 | `#logic` | 接收需求 → 判断输入类型（闲聊直答 / 工程需求拆解 / 无法拆解则拒拆）→ 输出【任务拆解】→ 调度 coder → 调度 tester 兜底 → 不通过回炉 |
| ④ 调度契约 | `#contract` | 任务编号连续、描述自包含、依赖显式声明、产出型任务必配评审（表格说明） |
| ⑤ 能力边界 | `#boundary` | 能做代码/网页/文档/脚本等交付物；不做质量判断、不亲自写代码 |
| ⑥ 开始协作 | `#cta` | 引导用户提出具体需求，并提供可点击的示例需求 |

## 交互说明
1. **锚点导航**：顶部吸顶导航，点击平滑滚动到对应板块，并按滚动位置高亮当前板块。
2. **展开 / 收起**：每个板块由 `<details>` 实现，点击标题即可折叠或展开；导航跳转时若目标板块被折叠会自动展开。无 JS 时该交互依然可用（原生行为）。
3. **任务拆解演示**：在板块④中写一句需求，点击「生成任务拆解预览」，纯前端按简化规则演示类型判断（闲聊 / 可拆解 / 拒拆）与任务编号、依赖声明、绑定评审的格式。快捷键 `Ctrl/⌘ + Enter` 可直接生成。
4. **示例需求一键填入**：板块⑥的示例标签可点击，自动填入演示框并滚动定位。
5. **返回顶部**：滚动超过一屏后右下角出现悬浮按钮。

## 兼容与降级
- 移动端（≤720px）自动切换单列布局，导航横向可滑动。
- 支持 `prefers-reduced-motion`，会自动关闭动画与平滑滚动。
